# シフト自動作成デモ 操作ガイド

## 1. 本書について

本書は、シフト自動作成デモを利用して、従業員登録からシフト生成、手動変更、CSV出力までを行う手順を説明する。

v1.1.0では、希望休のカレンダー入力、従業員別の月間シフト表示、個人用シフトカレンダーのCSV出力を追加している。

システム内部の設計やデータ構造ではなく、画面上の操作方法を中心に記載する。

---

## 2. アプリの起動

### 2.1 前提

次がインストールされていることを確認する。

- Python
- pip
- Git

---

### 2.2 リポジトリの取得

```bash
git clone https://github.com/rin-sato-tech/shift-scheduler.git
cd shift-scheduler
```

---

### 2.3 仮想環境の作成

```bash
python -m venv .venv
```

macOS・Linux：

```bash
source .venv/bin/activate
```

Windows：

```bash
.venv\Scripts\activate
```

---

### 2.4 パッケージのインストール

```bash
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

---

### 2.5 アプリの起動

```bash
streamlit run app.py
```

ブラウザでアプリが開く。

自動的に開かない場合は、ターミナルに表示されたローカルURLへアクセスする。

---

## 3. 基本的な操作順

初めて利用する場合は、左側のメニューから次の順番で操作する。

### シフト生成の準備

1. 従業員管理
2. 希望休入力
3. 必要人数設定

### シフトの作成と調整

1. シフト生成
2. 必要に応じてシフト手動変更

### 結果の出力

1. CSV出力

シフトを生成するには、少なくとも次の登録が必要である。

- 有効な従業員
- 必要に応じた責任者
- 対象月の全日・全シフトの必要人数
- 必要に応じた希望休

---

## 4. 従業員を登録する

左側のメニューから「従業員管理」を開く。

### 4.1 登録状況を確認する

画面上部に次の件数が表示される。

- 登録従業員数
- 有効従業員数
- 有効責任者数

その下に、登録済み従業員の一覧が表示される。

---

### 4.2 新しい従業員を登録する

「新規登録」で次を入力する。

| 項目             | 入力例           |
| ---------------- | ---------------- |
| 従業員ID         | `E001`           |
| 氏名             | `山田太郎`       |
| 月間契約勤務日数 | `20`             |
| 責任者として扱う | 必要に応じて選択 |
| 早番勤務可能     | 勤務可能なら選択 |
| 遅番勤務可能     | 勤務可能なら選択 |

入力後、「従業員を登録」を押す。

登録に成功すると、画面上部にメッセージが表示され、従業員一覧へ反映される。

---

### 4.3 登録時の注意

- 従業員IDは重複できない
- 氏名は空欄にできない
- 契約勤務日数は0〜31で入力する
- 早番・遅番の両方を勤務不可にはできない

従業員IDは登録後に変更できないため、入力前に確認する。

---

### 4.4 従業員情報を編集する

「編集・状態変更」で対象従業員を選ぶ。

変更できる項目：

- 氏名
- 月間契約勤務日数
- 責任者区分
- 早番勤務可否
- 遅番勤務可否

変更後、「変更を保存」を押す。

---

### 4.5 従業員を無効化する

退職や休職などにより新しいシフトへ含めない場合は、対象従業員を選び、「この従業員を無効化」を押す。

無効化すると、その従業員は以後の自動生成対象から除外される。

ただし、次のデータは自動削除されない。

- 登録済み希望休
- 保存済みシフト
- 過去の生成結果

---

### 4.6 従業員を再有効化する

無効な従業員を選択し、「この従業員を再有効化」を押す。

再有効化後は、新しいシフト生成の候補に含まれる。

---

## 5. 希望休を登録・削除する

左側のメニューから「希望休入力」を開く。

### 5.1 対象月を選ぶ

画面上部で年と月を選択する。

選択した対象月の日付が、月曜日始まりのカレンダーとして表示される。

---

### 5.2 希望休を登録する

「希望休を登録」で、対象の従業員を選択する。

従業員の表示例：

```text
E001｜山田太郎
```

カレンダー上で、希望休にしたい日付をクリックする。

複数の日付を選択できる。

選択中の日付を再度クリックすると、選択を解除できる。

選択した日付を確認し、「選択した希望休を登録」を押す。

登録後は、選択状態が解除され、登録済み希望休へ反映される。

---

### 5.3 カレンダーの状態

カレンダー上の日付は、次の状態に分かれる。

| 状態     | 意味                       |
| -------- | -------------------------- |
| 未選択   | 今回の登録対象ではない     |
| 選択中   | 今回登録する希望休         |
| 登録済み | すでに保存されている希望休 |
| 空欄     | 対象月外の日付             |

登録済みの日付は、新しい登録対象として選択できない。

---

### 5.4 登録できない場合

次の場合は希望休を登録できない。

- 有効な従業員がいない
- 日付を選択していない
- 対象従業員が無効である
- 同じ従業員・同じ日付がすでに登録されている

エラー内容を確認し、従業員または選択日を見直す。

---

### 5.5 登録済み希望休を確認する

「登録済み希望休」に、対象月の希望休が表示される。

表示内容：

- 日付
- 曜日
- 従業員ID
- 氏名
- 有効状態

「従業員で絞り込み」から、特定の従業員だけを表示できる。

---

### 5.6 希望休を削除する

「希望休を削除」で、対象の従業員を選択する。

選択した従業員の登録済み希望休が、カレンダー上に表示される。

削除したい日付をクリックする。

複数の日付を同時に選択できる。

削除選択中の日付を再度クリックすると、選択を解除できる。

選択内容を確認し、「選択した希望休を削除」を押す。

削除後は、選択状態が解除され、一覧とカレンダーへ反映される。

未登録の日付は削除対象として選択できない。

---

## 6. 必要人数を設定する

左側のメニューから「必要人数設定」を開く。

### 6.1 対象月を選ぶ

年と月を選択する。

対象月の全日付について、早番と遅番の行が表示される。

---

### 6.2 全日程へ一括設定する

多くの日で同じ人数が必要な場合は、「一括設定」を使用する。

例：

| 項目                   | 入力例 |
| ---------------------- | -----: |
| 全シフトの必要人数     |      2 |
| 全シフトの必要責任者数 |      1 |

入力後、「表全体に一括反映」を押す。

一括反映しただけではDBへ保存されないため、最後に保存操作が必要である。

---

### 6.3 日別に調整する

「日付・シフト別設定」の表で、必要に応じて次を変更する。

- 必要人数
- 必要責任者数

日付、曜日、シフトは変更できない。

例：

- 平日は2人
- 土日は3人
- 特定日の遅番だけ4人
- 責任者が不要なシフトは0人

---

### 6.4 入力時の注意

必要責任者数は、必要人数以下にする。

誤った例：

```text
必要人数：2
必要責任者数：3
```

この場合はエラーとなり、保存できない。

---

### 6.5 月間集計を確認する

表の下に次が表示される。

- 月間必要勤務枠
- 月間責任者枠
- 1シフト最大人数

月間必要勤務枠が、従業員の契約勤務日数合計から大きく離れていないか確認する。

---

### 6.6 設定を保存する

入力内容を確認し、「必要人数設定を保存」を押す。

保存成功後、画面上部にメッセージが表示される。

---

### 6.7 編集内容を取り消す

まだ保存していない編集を取り消す場合は、「保存済みの内容に戻す」を押す。

DBに保存済みの設定が再表示される。

---

## 7. シフトを自動生成する

左側のメニューから「シフト生成」を開く。

### 7.1 対象月を選ぶ

年と月を選択する。

選択した月は、次の形式で表示される。

```text
生成対象：2026年8月
```

---

### 7.2 入力データ状況を確認する

次の件数を確認する。

- 有効従業員
- 有効責任者
- 希望休
- 必要人数設定

必要人数設定は、次のように表示される。

```text
登録済み件数 / 必要件数
```

31日ある月では、早番・遅番を合わせて62件必要となる。

---

### 7.3 生成前チェックを確認する

「生成前チェック」に、入力データのエラーや警告が表示される。

#### エラー

エラーがある場合はシフトを生成できない。

例：

- 有効な従業員がいない
- 必要人数設定が不足している
- 勤務可能者が足りない
- 責任者候補が足りない
- 週5日上限を考慮すると配置数が足りない

#### 警告

警告だけの場合は生成できる。

例：

- 契約勤務日数合計が必要勤務枠より少ない
- 契約勤務日数合計が必要勤務枠より多い
- 契約勤務日数が対象月の日数を超えている

警告がある場合は、生成後の勤務日数差を確認する。

---

### 7.4 探索時間を選ぶ

次から選択する。

- 3秒
- 5秒
- 10秒
- 30秒

通常は10秒でよい。

解が見つからず`UNKNOWN`となる場合は、30秒へ延ばして再実行する。

---

### 7.5 既存シフトがある場合

対象月に保存済みシフトがある場合、再生成によって現在のシフトが置き換わる。

内容を確認し、次へチェックを入れる。

```text
既存シフトを置き換えることを確認しました
```

チェックを入れるまで生成ボタンは押せない。

手動変更済みのシフトも置き換わるため、必要に応じて先にCSVを出力する。

---

### 7.6 自動生成を実行する

「シフトを自動生成」を押す。

生成中は次のメッセージが表示される。

```text
シフトを生成しています...
```

処理が終わるまで、同じボタンを繰り返し押さない。

---

### 7.7 Solver結果を確認する

主な結果は次のとおりである。

| 表示       | 意味                                         |
| ---------- | -------------------------------------------- |
| 最適解     | 制約を満たし、目的関数上の最適性も確認された |
| 実行可能解 | 制約を満たす案は見つかったが、最適性は未証明 |
| 解なし     | すべての条件を同時に満たす案が存在しない     |
| モデル不正 | 最適化モデルに問題がある                     |
| 結果未確定 | 探索時間内に結果を確定できなかった           |

`最適解`または`実行可能解`であれば、制約を満たすシフト案が得られている。

---

### 7.8 乖離指標を確認する

次の2項目が表示される。

#### 最大契約日数乖離

最も契約勤務日数から離れた従業員の差である。

値が小さいほど、特定の従業員への大きな偏りが少ない。

#### 乖離合計

全従業員の契約勤務日数との差の合計である。

値が小さいほど、全体として契約勤務日数に近い。

---

### 7.9 月間シフトを確認する

「月間シフト」では、次の2つのタブを切り替えられる。

```text
日付別に見る
従業員別に見る
```

#### 日付別に見る

日付ごとの早番・遅番配置者を確認する。

主な確認項目：

- 各シフトに必要人数が配置されているか
- 責任者が配置されているか
- 特定の日に配置が偏っていないか

手動変更された配置者には`※`が付く。

#### 従業員別に見る

従業員ごとの1か月の勤務予定を確認する。

行は従業員、列は日付となる。

各セルには次のいずれかが表示される。

| 表示     | 意味               |
| -------- | ------------------ |
| 早       | 早番               |
| 遅       | 遅番               |
| 休       | 配置なし           |
| 早※・遅※ | 手動変更された配置 |

勤務区分は次のように色分けされる。

- 早番：青系
- 遅番：オレンジ系
- 休み：グレー系

横幅が広い場合は、表を横方向へスクロールして確認する。

#### 表示形式の使い分け

- 日付別表示：その日に誰が勤務するか確認する
- 従業員別表示：特定の従業員がいつ勤務するか確認する

---

### 7.10 配置明細を確認する

詳細を確認する場合は、配置明細の折りたたみ領域を開く。

主な表示項目：

- 日付
- 曜日
- シフト
- 従業員ID
- 氏名
- 責任者区分
- 手動変更の有無

---

### 7.11 保存済みシフトの検証

「保存済みシフトの検証」で、現在DBに保存されているシフトの状態を確認する。

日付別・従業員別のどちらの表示を選んでも、検証対象となる保存データは同じである。

問題がない場合は、すべての検証を通過したことが表示される。

---

### 7.12 従業員別勤務集計を確認する

各従業員について次を確認する。

- 契約勤務日数
- 割当勤務日数
- 差
- 早番回数
- 遅番回数
- 最大連続勤務日数
- 責任者配置回数

特に、契約勤務日数との差やシフト回数の偏りを確認する。

---

## 8. シフトを手動変更する

左側のメニューから「シフト手動変更」を開く。

### 8.1 前提

対象月のシフトが保存されていない場合は操作できない。

先に「シフト生成」で自動生成する。

---

### 8.2 対象月を選ぶ

変更したいシフトの年と月を選択する。

対象月を切り替えると、月ごとに別の編集案が使用される。

---

### 8.3 編集中のシフトを確認する

画面上部に、現在の編集案が月間表で表示される。

`※`が付いた配置は、手動変更された配置である。

---

### 8.4 配置を変更する

「配置を変更」で次を選ぶ。

1. 変更日
2. 従業員
3. 変更後の配置

変更後の選択肢：

- 早番
- 遅番
- 休み

「編集案へ反映」を押す。

この時点ではDBには保存されない。

---

### 8.5 現在の配置を確認する

フォーム下に、選択中の従業員・日付の現在の配置が表示される。

例：

```text
現在の配置：早番
```

変更前の確認に使用する。

---

### 8.6 編集案の検証を確認する

変更を反映すると、月間シフト全体が再検証される。

#### よく発生するエラー

- 必要人数が不足した
- 責任者が不足した
- 希望休の日に配置した
- 勤務不可のシフトへ配置した
- 週6日勤務になった
- 6日連続勤務になった

エラーがある場合は保存できない。

別の従業員を配置するなどして、エラーを解消する。

---

### 8.7 変更内容を確認する

「変更内容」に変更前と変更後が表示される。

例：

| 日付    | 従業員        | 変更前 | 変更後 |
| ------- | ------------- | ------ | ------ |
| 8月10日 | E001 山田太郎 | 早番   | 休み   |
| 8月10日 | E002 佐藤花子 | 休み   | 早番   |

複数の変更をまとめてから保存できる。

---

### 8.8 変更を保存する

次の条件を満たすと、「手動変更を保存」を押せる。

- 変更が1件以上ある
- エラーがない

保存すると、対象月のシフト全体が編集案へ置き換わる。

警告だけの場合は保存できるが、内容を確認してから実行する。

---

### 8.9 編集案を破棄する

保存前の変更をすべて取り消す場合は、「編集案を破棄」を押す。

編集案は削除され、DBに保存済みのシフトへ戻る。

すでに保存した変更は、この操作では元に戻らない。

---

## 9. CSVを出力する

左側のメニューから「CSV出力」を開く。

### 9.1 前提

対象月に保存済みシフトが必要である。

保存済みシフトがない場合は、先に「シフト生成」で生成する。

---

### 9.2 対象月を選ぶ

出力したい年と月を選択する。

保存済みの配置件数が表示される。

各出力データは、ダウンロード前に画面上で確認できる。

---

### 9.3 日付別月間シフト表を出力する

日付ごとの早番・遅番配置者を出力する。

主な列：

- 日付
- 曜日
- 早番
- 遅番

手動変更された配置者には`※`が付く。

「日付別月間シフト表をダウンロード」を押す。

ファイル名の例：

```text
shift_monthly_202608.csv
```

---

### 9.4 従業員別月間シフト表を出力する

従業員ごとの月間勤務を横並びで出力する。

主な列：

- 従業員ID
- 氏名
- 対象月の各日付

各日付には、`早`、`遅`、`休`のいずれかが出力される。

手動変更された配置には`※`が付く。

「従業員別月間シフト表をダウンロード」を押す。

ファイル名の例：

```text
shift_employee_monthly_202608.csv
```

---

### 9.5 個人用シフトカレンダーを出力する

個人用シフトカレンダーでは、出力対象の従業員を選択する。

選択した従業員の勤務が、月曜日始まりのカレンダー形式で表示される。

各セルの表示例：

```text
1日 早番
2日 休み
3日 遅番
```

内容を確認し、「個人用シフトカレンダーをダウンロード」を押す。

ファイル名の例：

```text
shift_calendar_E001_202608.csv
```

ファイル名には氏名ではなく、従業員IDが使用される。

---

### 9.6 配置明細を出力する

配置明細は、1件の配置を1行として出力する。

主な列：

- 日付
- 曜日
- シフト
- 従業員ID
- 氏名
- 責任者
- 手動変更

「配置明細をダウンロード」を押す。

ファイル名の例：

```text
shift_detail_202608.csv
```

---

### 9.7 従業員別勤務集計を出力する

勤務集計には次が含まれる。

- 契約勤務日数
- 割当勤務日数
- 差
- 早番回数
- 遅番回数
- 最大連続勤務日数
- 責任者配置回数

「勤務集計をダウンロード」を押す。

ファイル名の例：

```text
shift_summary_202608.csv
```

---

### 9.8 Excelで開く

CSVはUTF-8 BOM付きで出力されるため、通常はExcelで日本語が文字化けせずに開ける。

ただし、CSVには次の書式情報は保存されない。

- 背景色
- 罫線
- 列幅
- 印刷設定

セル幅や日付形式は、必要に応じてExcel側で調整する。

---

## 10. エラー・警告の見方

### 10.1 エラー

エラーは、生成または保存を続行できない問題である。

対応例：

| エラー             | 主な対応                         |
| ------------------ | -------------------------------- |
| 有効従業員がいない | 従業員を登録・再有効化する       |
| 責任者がいない     | 責任者区分を設定する             |
| 必要人数設定が不足 | 全日・全シフトを保存する         |
| 勤務可能者不足     | 従業員、希望休、必要人数を見直す |
| 責任者不足         | 責任者または必要責任者数を見直す |
| 必要人数不足       | 手動変更内容を修正する           |
| 希望休への配置     | 別日または別従業員へ変更する     |
| 週6日勤務          | 勤務日を休みに変更する           |
| 6日連続勤務        | 連続勤務の途中に休みを入れる     |

---

### 10.2 警告

警告があっても生成・保存できる。

ただし、次を確認する。

- 契約勤務日数との差
- 早番と遅番の偏り
- 責任者配置回数の偏り
- 必要勤務枠と契約勤務日数合計の差

警告が多い場合は、必要人数や契約勤務日数が現実的か確認する。

---

## 11. よくある問題

### 11.1 自動生成ボタンを押せない

主な原因：

- 生成前チェックにエラーがある
- 既存シフトの上書き確認にチェックしていない
- 生成処理を実行中である

画面上のエラーと注意事項を確認する。

---

### 11.2 必要人数設定が不足と表示される

対象月の表を開いただけでは保存されていない場合がある。

「必要人数設定を保存」を押し、全日・全シフトをDBへ保存する。

---

### 11.3 解なしになる

主な原因：

- 従業員数が足りない
- 責任者が足りない
- 希望休が集中している
- 早番・遅番の勤務可能者が偏っている
- 週5日と最大5連勤を同時に満たせない

入力データを見直し、再実行する。

---

### 11.4 結果未確定になる

探索時間を10秒から30秒へ延ばして再実行する。

それでも解が得られない場合は、条件が厳しすぎないか確認する。

---

### 11.5 手動変更を保存できない

次を確認する。

- 変更が実際に反映されているか
- 編集案にエラーがないか
- 必要人数が不足していないか
- 責任者が不足していないか
- 希望休や勤務不可シフトへ配置していないか

---

### 11.6 無効化した従業員が過去の一覧に残る

無効化は物理削除ではない。

過去の希望休や保存済みシフトを保持するため、一覧には残る。

新しい自動生成の候補からは除外される。

---

### 11.7 再生成したら手動変更が消えた

再生成は、対象月の保存済みシフト全体を新しい生成結果へ置き換える。

手動変更済みシフトを残したい場合は、再生成前にCSVを出力する。

---

### 11.8 希望休の日付を選択できない

次を確認する。

- すでに登録済みの日付ではないか
- 削除用カレンダーで未登録の日付を選んでいないか
- 有効な従業員を選択しているか

登録済みの日付は登録用カレンダーでは選択できず、未登録の日付は削除用カレンダーでは選択できない。

---

### 11.9 従業員別シフト表が横に長い

1か月分の日付を横並びで表示するため、画面幅を超える場合がある。

表を横方向へスクロールして確認する。

---

### 11.10 CSVに画面の色が反映されない

CSVはデータのみを保存する形式であり、画面上の背景色は保存されない。

早番・遅番・休みは、セル内の文字で確認する。

---

## 12. DB整合性の確認

必要に応じて、次のコマンドを実行する。

```bash
python scripts.check_db
```

主に次を確認する。

- 外部キー違反
- 同一従業員の同日重複配置
- 不正なシフト区分
- 必要なテーブル

問題がなければ正常終了する。

---

## 13. テストの実行

自動テストは次で実行する。

```bash
python -m pytest -v
```

特定の失敗を詳しく確認する場合：

```bash
python -m pytest -v --tb=long
```

実行時間の長いテストを確認する場合：

```bash
python -m pytest -v --durations=20
```

## 14. データの取扱い

本アプリはポートフォリオ用のローカルデモである。

次の点に注意する。

- 実在する従業員の機密情報を登録しない
- DBファイルを外部へ公開しない
- GitへDBファイルをコミットしない
- 本番の勤怠・給与計算には使用しない
- 複数人による同時編集を行わない

- 残業時間の計算
- 生成履歴の画面確認
- 手動変更履歴の確認
- Excelファイルへの直接出力
- 画面からのDB初期化
- 過去シフトへの自動復元
