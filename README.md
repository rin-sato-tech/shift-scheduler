# シフト自動作成デモ

従業員情報、希望休、必要人数をもとに、月間シフトを自動生成するデモアプリです。

## 想定機能

- 従業員登録
- 希望休入力
- 必要人数設定
- シフト自動生成
- 制約違反表示
- 手動変更
- CSV出力

## 技術スタック

- Python
- Streamlit
- SQLite
- pandas
- Google OR-Tools
- pytest

## 開発状況

WBS 11：シフト手動変更・再検証

## 従業員管理

従業員管理画面では、以下の操作を行える。

- 従業員の新規登録
- 氏名、責任者区分、契約勤務日数の変更
- 早番・遅番の勤務可否設定
- 従業員の無効化・再有効化

従業員は物理削除せず、
`is_active`によって自動生成対象かどうかを管理する。

## 希望休入力

希望休入力画面では、対象月を選択し、
従業員ごとの希望休を登録できる。

主な機能：

- 対象年月の選択
- 有効従業員への希望休登録
- 重複登録の防止
- 月別希望休一覧
- 従業員による絞り込み
- 希望休の削除

無効な従業員には新しい希望休を登録できない。
既に登録されている希望休は履歴確認のため一覧に残す。

## 必要人数設定

必要人数設定画面では、対象月の日付・シフトごとに
以下を設定できる。

- 必要人数
- 必要責任者数
- 全日・全シフトへの一括設定
- 日付・シフトごとの個別調整

必要責任者数は必要人数以下でなければならない。

対象月の全日付について、
早番・遅番の両方を設定する。

## シフト自動生成

シフト生成画面では、対象月を選択し、
登録済みの従業員、希望休、必要人数設定をもとに
月間シフトを自動生成する。

生成前に以下を確認する。

- 有効従業員の有無
- 責任者候補の有無
- 必要人数設定の不足
- 希望休を考慮した人員不足
- 契約勤務日数と必要勤務枠の差

生成結果は以下の形式で表示する。

- Solver状態
- 月間シフト表
- 制約違反・警告
- 従業員別勤務集計
- 契約勤務日数との差

生成結果がOPTIMALまたはFEASIBLEの場合のみ、
生成履歴とシフトをDBへ保存する。

## シフト手動変更

生成済みシフトは、対象月単位で編集できる。

手動変更は画面上の編集案へ反映し、
月間シフト全体を再検証してから保存する。

主な機能：

- 従業員・日付単位の配置変更
- 早番・遅番・休みへの変更
- 複数変更の一時保持
- 変更前後の差分表示
- ハード制約の再検証
- 警告表示
- 編集案の保存・破棄

ハード制約違反がある場合は保存できない。
変更された配置には`is_manual=True`を設定する。
