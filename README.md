# シフト自動作成デモ

従業員情報、希望休、必要人数をもとに、月間シフトを自動生成するデモアプリです。

## 想定機能

- 従業員登録
- 希望休入力
- 必要人数設定
- シフト自動生成
- 制約違反表示
- 手動変更
- CSV出力

## 技術スタック

- Python
- Streamlit
- SQLite
- pandas
- Google OR-Tools
- pytest

## 開発状況

WBS 9：必要人数設定画面の実装

## 従業員管理

従業員管理画面では、以下の操作を行える。

- 従業員の新規登録
- 氏名、責任者区分、契約勤務日数の変更
- 早番・遅番の勤務可否設定
- 従業員の無効化・再有効化

従業員は物理削除せず、
`is_active`によって自動生成対象かどうかを管理する。

## 希望休入力

希望休入力画面では、対象月を選択し、
従業員ごとの希望休を登録できる。

主な機能：

- 対象年月の選択
- 有効従業員への希望休登録
- 重複登録の防止
- 月別希望休一覧
- 従業員による絞り込み
- 希望休の削除

無効な従業員には新しい希望休を登録できない。
既に登録されている希望休は履歴確認のため一覧に残す。

## 必要人数設定

必要人数設定画面では、対象月の日付・シフトごとに
以下を設定できる。

- 必要人数
- 必要責任者数
- 全日・全シフトへの一括設定
- 日付・シフトごとの個別調整

必要責任者数は必要人数以下でなければならない。

対象月の全日付について、
早番・遅番の両方を設定する。
