# シフト自動作成デモ

従業員情報、希望休、必要人数をもとに、月間シフトを自動生成するデモアプリです。

## 想定機能

- 従業員登録
- 希望休入力
- 必要人数設定
- シフト自動生成
- 制約違反表示
- 手動変更
- CSV出力

## 技術スタック

- Python
- Streamlit
- SQLite
- pandas
- Google OR-Tools
- pytest

## 開発状況

WBS 0：プロジェクト準備

## 従業員管理

従業員管理画面では、以下の操作を行える。

- 従業員の新規登録
- 氏名、責任者区分、契約勤務日数の変更
- 早番・遅番の勤務可否設定
- 従業員の無効化・再有効化

従業員は物理削除せず、
`is_active`によって自動生成対象かどうかを管理する。
